Hãy tiếp tục phát triển dự án React Vite “Vui học Tin học 3 – Thế giới Robot Pastel” từ các file đính kèm / repository. GIỮ NGUYÊN toàn bộ 16 bài theo đúng tên trong src/data.js, 6 chủ đề, 48 câu hỏi, sáu trò chơi hoạt động thật, bản đồ mở khóa, điểm sao, góc giáo viên, thi đấu nhóm, giọng đọc Web Speech API và localStorage. Không thay bằng mockup hoặc giao diện tĩnh. Giữ phong cách pastel tím xanh hồng, nhân vật Bé Bít CSS, tối ưu cả màn hình phòng máy và điện thoại. Kiểm thử npm install, npm run build, thử từng trò chơi bằng tương tác thực tế; sửa lỗi logic, lỗi bàn phím, touch và accessibility. Không giả vờ có đồng bộ dữ liệu trực tuyến. Nếu muốn bảng quản lý lớp trên nhiều thiết bị, hãy hỏi trước và chỉ triển khai bằng Firebase Authentication + Firestore cùng quy tắc phân quyền rõ ràng. Không đưa API key bí mật vào client. Viết tiếng Việt chuẩn, ưu tiên dễ đọc với học sinh lớp 3.
